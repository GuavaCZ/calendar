# Interactions

By now you should have a perfectly fine and working calendar. However, it is still very static - you can view your events, but there is no way to interact with them.

The calendar supports many ways to interact with it: clicking dates and events, context menus, drag & drop, resizing and more. All of them are opt-in, so you only enable what you need.

Please start with the [actions](01-actions.md) page, since almost every interaction builds on it.
